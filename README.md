# 槐湾孤儿院

单人悬疑恐怖网页叙事解谜。项目为纯静态网页，可部署到任意静态站点。

## 运行

直接部署 `dist/` 目录即可。Windows 本地试玩可双击 `RUN_LOCAL_WINDOWS.bat`；它会在本机启动静态服务器并打开浏览器。

## 重新构建

双击 `BUILD_WINDOWS.bat`。批处理会调用 `tools/build.py`，执行资源清理、SVG 压缩、资源引用检查、零音频资产检查、生成构建清单，并输出 `dist/` 与 `release/槐湾孤儿院_发布文件.zip`。

## 设计硬约束

- 全程无 BGM；项目不包含任何音频文件。
- 所有谜题只依赖 HTML 可读文字、记录、锚点状态与因果关系。
- 插画只承担场景、人物动作和氛围；删除全部插画后，核心谜题仍可完成。
- 无找不同、数物件、图像比对、颜色编码、辨音、听顺序、密码输入、限时 QTE 或追逐。
- 支持鼠标、触控和键盘；无拖拽强制操作。
- 自动保存地点、记录、谜题与锚点状态；刷新后可继续。
- 支持较大文字与减少动态。

## 目录

- `src/`：源代码与原始 SVG 资产。
- `dist/`：构建后的可部署版本。
- `tools/`：构建与美术资产生成脚本。
- `qa/`：多轮自动检查报告与严格要求评分表。
- `release/`：发布压缩包。

## 说明

当前环境为 Linux，无法直接启动 Windows `cmd.exe` 执行 `.bat`。交付中的 `BUILD_WINDOWS.bat` 仅作为 Windows 包装入口；本次交付已经实际执行了它所调用的同一 `tools/build.py` 构建流程，因此 `dist/` 与发布压缩包均为处理后的产物。
